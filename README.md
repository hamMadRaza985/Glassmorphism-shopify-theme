# Andri Watches – Shopify Theme

A dark, premium, gold-accent Shopify Online Store 2.0 theme recreated from the supplied visual reference.

## Included
- Glassmorphism header/navigation
- Hero section with image picker and CTA
- Trust/features strip
- 4 category cards
- Shopify collection-powered bestseller grid
- Premium quality CTA banner
- Responsive desktop/tablet/mobile layouts
- Theme Editor settings and section schemas
- Native Shopify Liquid objects for products, collections, cart, search, account and navigation

## Install
1. In Shopify Admin, go to **Online Store → Themes**.
2. Choose **Add theme → Upload zip file**.
3. Upload the ZIP.
4. Open **Customize**.
5. Add/select your logo, hero image, category images, premium banner image, navigation menus and bestseller collection.

## Matching the reference
For the closest visual match, use:
- Black/charcoal photography with warm gold highlights.
- Product photos on dark backgrounds.
- A transparent PNG/SVG logo if you have the original brand logo.
- A 16:9 hero image showing a premium watch in a black/gold setting.

The theme is intentionally editable rather than hard-coding the reference screenshot into the storefront.
